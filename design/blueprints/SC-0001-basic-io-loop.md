## 1. 场景概述

本场景是商场运行的**最小可行演示（MVD）**。它验证商场最核心的三条铁律：
- 函数无状态性（键盘捕获函数每次调用独立）
- SHM数据路由（商场作为唯一物流通道）
- 消费者验收权（Console显示即默认验收）

## 5. 运行时序流程

### 阶段A：初始化（T0 ~ T1）

```
T0: 商场main()启动
    └─→ 初始化SHM内存池
    └─→ 加载已授权函数注册表
    └─→ 创建 `/shm/keyboard/raw_input` 矢量槽位（容量：1024条记录环形缓冲）

T0+Δt: 键盘生产者初始化
    └─→ 商场验证生产者授权文件（BP-0001签名）
    └─→ 分配写入句柄至 `/shm/keyboard/raw_input`
    └─→ 生产者进入监听循环（非阻塞主进程）

T0+2Δt: Console消费者初始化
    └─→ 商场验证消费者授权文件（BP-0002签名）
    └─→ 分配读取句柄，订阅 `/shm/keyboard/raw_input`
    └─→ 消费者进入等待循环（阻塞于SHM空信号）
```

### 阶段B：生产-路由-消费（T1起，循环）

```
T1: 用户按下 'A'
    └─→ 操作系统捕获键盘中断
    └─→ 键盘生产者 capture_key() 被调度执行
        ├─→ 读取键码（0x1E）
        ├─→ 组装数据包（见4.1格式）
        ├─→ 调用 mall_shm_write(vector_id, packet)
        └─→ 函数返回，状态清零（无状态铁律）

T1+ε: 商场SHM层检测到写入事件
    ├─→ 校验生产者权限（是否拥有该矢量写入权）
    ├─→ 校验数据格式（版本、必填字段）
    ├─→ 写入环形缓冲，更新读指针
    └─→ 触发订阅通知：console_consumer

T1+2ε: Console消费者被唤醒
    └─→ display_packet() 被调度执行
        ├─→ 从SHM读取数据包
        ├─→ 格式化输出：`[keyboard] 2026-05-10T13:30:45.123456789 'A' (press)`
        ├─→ 写入stdout
        └─→ 函数返回，状态清零

T1+3ε: 商场记录交易日志
    └─→ 生产者信用分 +1（成功交付）
    └─→ 消费者验收状态："auto_accepted"（Console无显式拒绝机制）
```

## 6. 商场调度逻辑细节

### 6.1 生产者调度策略

```python
# 伪代码：商场对键盘生产者的调度
while mall_is_running:
    # 键盘生产者采用事件驱动，非轮询
    if os_keyboard_event_available():
        # 从算力进程池分配临时Worker
        worker = process_pool.acquire()
        worker.execute(capture_key, shm_handle=keyboard_vector)
        # 执行完毕立即释放，不保留状态
        process_pool.release(worker)
    # 不阻塞主进程，yield CPU
    mall_yield()
```

### 6.2 消费者订阅匹配规则

```
订阅表达式：console_consumer.subscription = {
    "producer_id": "*",           # 接受任何生产者
    "product_type": "keyboard.raw", # 精确匹配产品类型
    "min_version": 1,             # 最低版本要求
    "delivery_mode": "push"        # 推送模式（非拉取）
}
```

商场匹配引擎：当 `/shm/keyboard/raw_input` 有新数据时，扫描所有订阅者，
若 `product_type` 匹配且权限有效，则投递通知信号。

## 7. 异常处理点

| 异常场景 | 触发条件 | 商场响应 | 生产者后果 | 消费者影响 |
|----------|----------|----------|------------|------------|
| **SHM溢出** | 键盘输入过快，环形缓冲写满 | 丢弃最旧数据，记录溢出事件 | 信用分不变（非恶意） | 可能丢失早期按键 |
| **格式违规** | 数据包缺少 `key_code` 字段 | 拒收数据，返回错误码 | 信用分 -5，连续3次则暂停授权 | 无影响（数据未进入SHM） |
| **权限伪造** | 生产者尝试写入未授权矢量 | 拒绝写入，触发安全审计 | 信用分 -50，冻结授权 | 无影响 |
| **消费者崩溃** | Console进程意外退出 | 检测到订阅者失效，清理句柄 | 无影响 | 商场标记消费者离线，数据暂存 |
| **商场主进程中断** | 收到SIGTERM | 优雅关闭：冻结SHM写入，通知所有参与者保存状态，清理资源 | 生产者收到终止信号，停止捕获 | 消费者收到终止信号，停止显示 |
