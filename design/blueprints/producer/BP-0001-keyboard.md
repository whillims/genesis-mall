## 2. 功能概述

实现一个**键盘输入回显函数**。接收用户通过键盘输入的字符串，执行输入校验，将内容输出至标准控制台（Console / stdout），并返回结构化的执行结果。

**数据来源固定为 `keyboard`，不可配置为其他来源。**

------------------------------------------------------------------------

## 3. 函数设计（函数级，无类）

### 3.1 主函数签名

```python
def keyboard_echo(user_input: str, config: dict | None = None) -> dict:
    """
    键盘生产者输入回显函数。

    将经校验的键盘输入内容输出至控制台，并返回执行状态。

    Args:
        user_input: 用户通过键盘输入的原始文本。
        config: 可选运行时配置字典。

    Returns:
        包含显示状态、时间戳与元数据的字典。
    """
```

### 3.2 参数规格

| 参数 | 类型 | 必填 | 约束条件 | 说明 |
| --- | --- | --- | --- | --- |
| `user_input` | `str` | 是 | 经`strip()`后非空；长度 ≤ 1024；仅可打印UTF-8字符 | 键盘输入的原始文本 |
| `config` | `dict` | 否 | 见下方配置契约 | 运行时参数覆盖 |

#### 配置契约（config字典）

```python
{
    "source": "keyboard",           # 固定值，必须为"keyboard"
    "echo_prefix": str,             # 控制台输出前缀，默认 "[KEYBOARD] "
    "enable_timestamp": bool        # 是否在输出后附加时间戳，默认True
}
```

> **来源锁定原则**：`config` 中若传入 `source` 且值不为 `"keyboard"`，直接触发 **E009**。若未传入 `source`，默认视为 `"keyboard"`。

### 3.3 数据来源（source）定义

| 来源标识 | 含义 | 校验策略 |
| --- | --- | --- |
| `keyboard` | 本地物理键盘输入 | 标准校验：长度、字符集、空白过滤 |

### 3.4 返回值规格

返回字典必须包含以下字段，**不得缺失、不得扩展未声明字段**：

```python
{
    "status": "success" | "error",      # 执行状态
    "displayed": bool,                  # 是否成功输出到控制台
    "timestamp": str,                   # ISO 8601格式UTC时间戳
    "source": "keyboard",               # 数据来源标识，固定回显"keyboard"
    "metadata": {
        "input_length": int,            # 实际输入字符数（strip后）
        "processing_ms": int,           # 处理耗时（毫秒），≥ 0
        "version": str                  # 蓝图版本，固定 "2.0.0"
    },
    "error": {
        "code": str | None,             # 错误码，成功时为None
        "message": str | None           # 错误描述，成功时为None
    }
}
```

## 4. 行为契约

### 4.1 前置条件（Preconditions）

1. `user_input` 类型必须为 `str`，否则触发 **E004**。
2. `user_input` 经 `strip()` 处理后长度必须 > 0，否则触发 **E001**。
3. `user_input` 长度（strip后）必须 ≤ 1024，否则触发 **E002**。
4. `user_input` 必须仅包含可打印UTF-8字符（正则：`^[\p{Print}\p{Han}\s]*$`），否则触发 **E005**。
5. `config` 若包含 `source` 字段，其值必须为 `"keyboard"`，否则触发 **E009**。

### 4.2 后置条件（Postconditions）

1. 返回值为 `dict` 类型，包含全部声明字段。
2. `status` 字段只能是 `"success"` 或 `"error"`。
3. `timestamp` 必须为有效ISO 8601 UTC格式字符串，以 `Z` 结尾。
4. `processing_ms` 必须 ≥ 0，且为整数。
5. `source` 字段固定为 `"keyboard"`。
6. 若 `status == "success"`：
   - `displayed == True`
   - `error.code == None`
   - 控制台已实际输出内容（前缀 + 输入文本 + 可选时间戳）
7. 若 `status == "error"`：
   - `displayed == False`
   - `reply`（控制台无输出或输出错误提示，视实现而定）
   - `error.code` 非空

### 4.3 不变量（Invariants）

- 函数执行过程中**不得修改任何全局状态**。
- 函数**不得进行文件系统I/O**（`open`, `os.open`, `pathlib` 等）。
- 函数**不得发起网络请求**。
- 函数**不得访问环境变量或系统配置**（除显式传入的`config`外）。
- 函数**允许向 stdout 输出**，因为这是本函数的核心功能契约（Console显示）。
- 函数**不得向 stderr 输出**（错误信息应封装在返回值中）。

### 4.4 控制台输出格式

当 `status == "success"` 时，控制台输出格式为：

```
[KEYBOARD] {user_input} | 2026-05-10T07:03:00Z
```

其中：
- `[KEYBOARD]` 为默认前缀，可通过 `echo_prefix` 覆盖。
- 时间戳仅在 `enable_timestamp == True` 时附加，格式为 `| {ISO_TIMESTAMP}`。
- 输出末尾自动追加 `\n`。

### 4.5 错误契约

| 错误码 | 触发条件 | 返回状态 | 控制台行为 |
| --- | --- | --- | --- |
| `E001` | 输入为空或仅含空白字符 | `error` | 无输出 |
| `E002` | 输入超出长度限制（>1024） | `error` | 无输出 |
| `E003` | 内部运行时异常 | `error` | 无输出 |
| `E004` | 参数类型错误 | `error` | 无输出 |
| `E005` | 输入包含非法字符 | `error` | 无输出 |
| `E009` | 来源标识非法（非keyboard） | `error` | 无输出 |

## 5. 测试场景（验收标准）

### TC-001：正常键盘输入回显

- **输入**：`user_input="Hello, 商场!"`
- **配置**：默认
- **预期**：
  - `status == "success"`
  - `displayed == True`
  - `source == "keyboard"`
  - 控制台输出：`[KEYBOARD] Hello, 商场! | 2026-05-10T...Z`
  - `metadata.input_length == 10`

### TC-002：空输入

- **输入**：`user_input=""`
- **预期**：
  - `status == "error"`
  - `error.code == "E001"`
  - `displayed == False`
  - 控制台无输出

### TC-003：仅空白字符

- **输入**：`user_input="   \n\t  "`
- **预期**：同TC-002，触发E001

### TC-004：超长输入

- **输入**：`user_input="x" * 1025`
- **预期**：
  - `status == "error"`
  - `error.code == "E002"`
  - `displayed == False`

### TC-005：自定义前缀

- **输入**：`user_input="创世纪信号"`
- **配置**：`{"echo_prefix": "[GENESIS]>>> "}`
- **预期**：
  - `status == "success"`
  - 控制台输出：`[GENESIS]>>> 创世纪信号 | 2026-05-10T...Z`

### TC-006：禁用时间戳

- **输入**：`user_input="无时间戳测试"`
- **配置**：`{"enable_timestamp": False}`
- **预期**：
  - `status == "success"`
  - 控制台输出：`[KEYBOARD] 无时间戳测试`（无尾部时间戳）

### TC-007：非法来源标识

- **输入**：`user_input="测试"`
- **配置**：`{"source": "network"}`
- **预期**：
  - `status == "error"`
  - `error.code == "E009"`
  - `displayed == False`

### TC-008：非法字符输入

- **输入**：`user_input="test\x00end"`
- **预期**：
  - `status == "error"`
  - `error.code == "E005"`
  - `displayed == False`

### TC-009：参数类型错误

- **输入**：`user_input=12345`（非str）
- **预期**：
  - `status == "error"`
  - `error.code == "E004"`

### TC-010：性能基准

- **输入**：`user_input="性能测试" * 50`
- **预期**：`processing_ms < 5`

## 7. 安全与隔离铁律

1. **文件系统零I/O**：禁止 `open()`、`os.open()`、`pathlib` 等任何文件操作。
2. **网络零I/O**：禁止 `socket`、`urllib`、`requests` 等任何网络操作。
3. **stdout特许**：本函数核心功能为Console显示，**允许且仅允许**向 `sys.stdout` 输出经校验的内容。
4. **stderr静默**：禁止向 `sys.stderr` 输出，所有错误信息必须封装在返回值字典中。
5. **零全局副作用**：不得修改 `global`、`nonlocal` 变量，不得缓存状态到模块级字典。
6. **输入消毒**：所有输入必须经过长度、类型、字符集三重校验，拒绝任何未通过校验的数据进入输出逻辑。
7. **确定性输出**：相同输入 + 相同配置，必须在任意时刻产生结构一致的返回值（时间戳字段除外）。

## 8. 授权文件生成要求（致外置AICoder）

外置AICoder收到本蓝图后，应执行以下动作：

1. **契约审查**：验证函数签名、参数类型、返回值结构、来源锁定策略是否与蓝图第3节完全一致。
2. **代码生成**：根据蓝图生成纯函数级Python代码，**禁止生成类、禁止生成装饰器封装、禁止OOP模式**。
3. **测试覆盖**：生成对应TC-001至TC-010的自动化测试代码，全部通过方可进入下一步。
4. **安全扫描**：静态检查代码中是否存在文件I/O、网络I/O、全局状态修改、stderr输出，存在则拒绝授权。
5. **stdout合规确认**：确认代码中唯一的I/O行为是向 `sys.stdout.write()` 或 `print()` 输出经校验的内容。
6. **授权文件输出**：生成标准授权文件（`AUTH-BP-0001-ORIGIN.json`），包含：
   - 蓝图ID与版本
   - AICoder审查结论（通过/拒绝）
   - 生成的完整函数代码（字符串形式）
   - 测试报告摘要（10项全部PASS）
   - 数字签名字段（由AICoder私钥签署）
