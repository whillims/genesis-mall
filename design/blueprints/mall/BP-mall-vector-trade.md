## 2. 矢量通道

### 2.1 通道类型

| 通道 | 方向 | 说明 |
|------|------|------|
| `VEC-PUB-{producer_id}` | 生产者→消费者 | 产品发布（环形缓冲区） |
| `VEC-RECEIPT` | 消费者→商场 | 回执确认（环形缓冲区） |
| `VEC-CONTROL` | 商场→所有 | 节奏调节/配额通知 |

### 2.2 帧结构

```python
# 产品帧
{
    "seq": 12345,                    # 序列号（用于遗漏检测）
    "timestamp": 1715500000.123,    # 发布时间
    "producer_id": "RTL-001",       # 生产者标识
    "consumer_ids": ["CT-001"],     # 目标消费者（可选）
    "vector_type": "SYNTH_spectrum", # 矢量类型
    "payload": {...},               # 实际数据
    "ttl": 30,                     # 生存时间（秒）
    "priority": 5                  # 优先级（1-10）
}

# 回执帧
{
    "seq": 12345,                  # 对应的产品序列号
    "consumer_id": "CT-001",       # 消费者标识
    "product_id": "RTL-001",       # 生产者标识
    "task_id": 1,                  # 任务ID（可选）
    "status": "accepted",          # accepted / rejected / partial
    "received_at": 1715500000,     # 接收时间
    "digest": "sha256:abc...",     # 产品摘要（防篡改）
    "note": ""                     # 备注
}

# 控制帧
{
    "type": "rate_limit",          # rate_limit / quota_update / pause / resume
    "target_id": "RTL-001",        # 目标生产者
    "rate_hz": 2.0,               # 限制频率（Hz）
    "message": "矢量缓冲区接近满载，请降速"
}
```

## 3. 矢量管理器

### 3.1 核心API

```python
class VectorManager:
    def allocate(producer_id: str, vector_type: str, size: int) -> str
        """分配矢量，返回矢量ID"""

    def release(vector_id: str) -> bool
        """释放矢量"""

    def publish(vector_id: str, frame: dict) -> bool
        """发布帧到矢量（环形缓冲区）"""

    def subscribe(vector_id: str) -> Iterator[dict]
        """订阅矢量，返回帧迭代器"""

    def read_new(vector_id: str, last_seq: int) -> List[dict]
        """读取新帧（从last_seq之后）"""

    def get_stats(vector_id: str) -> dict
        """获取矢量统计"""

    def set_quota(consumer_id: str, quota_bytes: int) -> bool
        """设置消费者配额"""

    def get_quota_usage(consumer_id: str) -> dict
        """获取配额使用情况"""
```

### 3.2 溢出保护

- 固定大小环形缓冲区（默认1MB）
- 写入前检查剩余空间
- 溢出时：
  1. 丢弃最旧帧
  2. `overflow_count++`
  3. 发布rate_limit控制帧

### 3.3 遗漏检测

- 通过序列号连续性检测丢包
- 检测到遗漏时记录日志
- 商场可决定是否重发

## 4. 交易流程

### 4.1 即时交易（无需同步）

```
1. 消费者订阅 VEC-PUB-{producer_id}
2. 生产者发布产品到 VEC-PUB-{producer_id}
3. 消费者收到产品
4. 消费者发布回执到 VEC-RECEIPT
5. 商场消费回执 → 扣减预算 → 交易完成
```

### 4.2 批量同步交易（屏障同步）

```
1. 商场创建监督Worker，配置屏障: consumers=["CT-001","CT-002","CT-003"]
2. 生产者发布p1到 VEC-PUB-{producer_id}
3. 监督Worker记录: p1已发布，等待3个回执
4. CT-001收到p1，发布回执到 VEC-RECEIPT
5. CT-002收到p1，发布回执到 VEC-RECEIPT
6. CT-003收到p1，发布回执到 VEC-RECEIPT
7. 监督Worker检测到3/3，发布完成反馈到 VEC-FEEDBACK
8. 商场收到反馈，通知生产者: 发p2
9. 重复直到所有产品完成 → 任务结束
```

## 5. 监督Worker

### 5.1 职责

| 职责 | 说明 |
|------|------|
| **屏障状态** | 跟踪每个产品有多少消费者已确认 |
| **进度上报** | 向商场报告：n/m消费者已确认 |
| **完成判定** | 所有消费者都确认后，触发下一产品 |
| **失败处理** | 超时未收到某消费者回执，通知商场 |
| **任务结束** | 所有产品都完成，通知商场任务结束 |

### 5.2 状态机

```
WAITING     → 等待产品发布
   ↓
RECEIVING  → 等待消费者回执
   ↓ (n/n回执)
NEXT_READY → 通知商场可发下一产品
   ↓
DONE       → 任务完成
   ↓ (失败)
FAILED      → 通知商场任务失败
```

### 5.3 配置

```python
supervisor_config = {
    "task_id": 1,
    "producer_id": "RTL-001",
    "consumers": ["CT-001", "CT-002", "CT-003"],
    "products": ["p1", "p2", "p3"],
    "timeout_seconds": 30,      # 单产品超时
    "retry_count": 3,           # 失败重试次数
    "on_complete": "notify_mall" # 完成后动作
}
```

## 6. 商场本体职责

### 6.1 矢量管理

- 创建/销毁矢量
- 配额管理
- 溢出监控

### 6.2 交易结算

- 消费 VEC-RECEIPT
- 验证回执
- 扣减预算
- 记录审计

### 6.3 监督Worker管理

- 创建/销毁监督Worker
- 接收反馈
- 处理完成/失败

### 6.4 节奏调节

- 监控 VEC-CONTROL
- 检测溢出
- 发布降速指令
