## 一、核心定义

| 关键词 | 定义 |
|--------|------|
| **消费者 (Consumer)** | 在商场SHM生态中，以**消费意图**驱动，通过订阅或指定方式获取生产者数据资产，并承担相应时间代价的函数级实体。 |
| **消费意图 (Intent)** | 消费者向商场声明的、具有明确数据特征与时效边界的需求描述，是商场进行生产者匹配的唯一合法依据。 |
| **消费者相 (Consumer Phase)** | 消费者对外呈现的观测界面，是数据资产的最终渲染形态。UI组件是消费者相的物理载体。 |
| **消费者展示广场 (Consumer Plaza)** | 由网页或终端容器承载的、多消费者相的聚合可视化空间，每个相独立渲染，互不干涉。 |
| **时间代价 (Time Cost)** | 消费者为获取指定生产者产出而必须承担的、以调度延迟为计量单位的契约代价，具有随机性与不可压缩性。 |
| **消费者资产 (Consumer Asset)** | 消费者通过合法消费行为积累的数据产物、任务集、状态快照，归消费者所有，商场仅提供SHM托管。 |

---

## 二、消费者第一性原理

```
公理 1: 消费者是需求的源头，但消费者不直接生产函数。
公理 2: 消费者意图必须通过商场SHM总线投递，禁止与消费者直连。
公理 3: 消费者拥有其消费产物的完整所有权，商场无权篡改或转售。
公理 4: 消费者的时间代价不可被生产者或商场单方面免除，代价是契约的基石。
公理 5: 消费者可以消亡，但其消费历史与资产必须由商场持久化至少一个审计周期。
```

## 三、消费者与商场的关系拓扑

```
                    ┌─────────────────────────────────────┐
                    │           商场 SHM 总线              │
                    │  ┌─────────┐      ┌─────────────┐   │
    消费者意图 ──────→ │ 意图匹配 │ ───→ │ 生产者调度  │   │
    (Intent)          │  引擎    │      │  (Blueprint)│   │
                    │  └─────────┘      └─────────────┘   │
                    │         ↓ 产出物 (Product)            │
                    │  ┌─────────────────────────────┐      │
                    │  │    消费者相 (Consumer Phase)  │      │
                    │  │    UI组件 / Console / 文件   │      │
                    │  └─────────────────────────────┘      │
                    └─────────────────────────────────────┘
```

**关系铁律**:
- 消费者 ↔ 商场: 意图委托关系。消费者将意图委托给商场，商场负责匹配与调度。
- 消费者 ↮ 生产者: **绝对禁止**。任何绕过商场的直接消费行为视为对SHM宪法的背叛。
- 消费者 ↔ 消费者: 无直接交互。消费者之间的数据交换必须通过生产者-商场-消费者链路完成。

## 四、消费者画像维度

消费者画像由以下五个正交维度构成，任一消费者实体必须在这五维空间中被唯一标定：

| 维度 | 标识符 | 说明 |
|------|--------|------|
| **消费模式 (Mode)** | `M` | 订阅型 / 指定型 / 混合型 |
| **时效等级 (Latency)** | `L` | 实时级(L0) / 准实时级(L1) / 延迟容忍级(L2) / 批处理级(L3) |
| **资产敏感度 (Sensitivity)** | `S` | 公开级(S0) / 内部级(S1) / 机密级(S2) / 绝密级(S3) |
| **代价承受力 (Budget)** | `B` | 无限(B∞) / 高(B2) / 中(B1) / 低(B0) |
| **生命周期 (Lifecycle)** | `C` | 瞬态(C0) / 会话态(C1) / 持久态(C2) / 永恒态(C3) |

**画像编码示例**: `M-sub/L1/S1/B1/C2` 表示一个订阅型、准实时、内部敏感度、中等预算、持久生命周期的消费者。

## 五、消费者权利法案

```
权利 1: 意图表达权
    消费者有权以任意合法格式表达消费意图，商场不得拒绝或曲解。

权利 2: 生产者知情权
    在指定型消费中，消费者有权获知目标生产者的蓝图摘要、
    历史稳定性评分及预计时间代价区间。

权利 3: 代价申诉权
    当实际时间代价超出预估区间上限的200%时，
    消费者有权向商场审计沙箱发起代价申诉。

权利 4: 资产处置权
    消费者对其消费产物拥有下载、转储、销毁的绝对权力，
    商场仅提供SHM托管，不拥有任何处置权。

权利 5: 熔断避难权
    当生产者持续异常或商场拥堵时，消费者有权启动消费熔断，
    转入降级消费模式或安全退出。

权利 6: 历史追溯权
    消费者有权查询自身在一个审计周期内的全部消费记录、
    时间代价明细及生产者履约情况。
```

## 六、消费者义务宪章

```
义务 1: 意图真实性义务
    消费者不得提交虚假意图诱导生产者生产无关产物，
    虚假意图将被商场意图匹配引擎标记并降权。

义务 2: 代价承受义务
    一旦发起指定型消费，消费者必须接受实际时间代价，
    不得以"等待过久"为由单方面撕毁契约。

义务 3: 资产清理义务
    瞬态与会话态消费者必须在生命周期终止前显式释放
    其占用的SHM矢量区块，否则商场将强制回收并记录信用污点。

义务 4: 安全隔离义务
    消费者不得试图读取其他消费者的SHM矢量区块，
    任何越界访问将被商场安全铁律立即熔断。

义务 5: 外域合规义务
    当消费者产物需要发往商场外域时，消费者必须确保
    该外发行为不违反商场安全总则与外域数据协定。
```
